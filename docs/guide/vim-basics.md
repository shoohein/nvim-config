# Vim 基本操作

Neovimで編集を始めるために必要な最小限の操作です。`operator + motion`の原則がわかれば、あとは`:help`で調べられます。

## モード

Vimには主要なモードが4つあります。左下に現在のモードが表示されます。

| モード | 入り方 | 戻り方 | 用途 |
|---|---|---|---|
| Normal | `Esc` | — | 移動、コマンド、操作の起点 |
| Insert | `i`, `a`, `o` など | `Esc` または `jj` | 文字入力 |
| Visual | `v`, `V`, `Ctrl-v` | `Esc` | 範囲選択 |
| Command-line | `:` | `Esc` または Enter | 保存、終了、検索、置換 |

## 保存と終了

| キー | 動作 |
|---|---|
| `:w` | 保存 |
| `:q` | 終了 |
| `:wq` | 保存して終了 |
| `:q!` | 保存せずに終了 |

## 移動

| キー | 動作 |
|---|---|
| `h`, `j`, `k`, `l` | 左、下、上、右 |
| `w`, `b` | 次の単語の先頭、前の単語の先頭 |
| `0`, `^` | 行頭、行の最初の非空白文字 |
| `$` | 行末 |
| `gg`, `G` | ファイルの先頭、末尾 |
| `:<数字>` | 指定行へ移動 |
| `{`, `}` | 段落単位の移動 |

## 挿入

| キー | 動作 |
|---|---|
| `i` | カーソル位置から挿入 |
| `a` | カーソルの次から挿入 |
| `o` | 下に新しい行を作って挿入 |
| `O` | 上に新しい行を作って挿入 |

## 削除・変更

| キー | 動作 |
|---|---|
| `x` | カーソル下の1文字を削除 |
| `d` | 移動コマンドと組み合わせて削除（例: `dw` 単語削除、`dd` 行削除） |
| `c` | 削除してそのままInsert mode（例: `cw` 単語変更、`cc` 行変更） |
| `C` | カーソル位置から行末まで変更 |
| `D` | カーソル位置から行末まで削除 |
| `s` | カーソル下の1文字を削除してInsert mode |

## コピーと貼り付け

| キー | 動作 |
|---|---|
| `y` | 移動コマンドと組み合わせてコピー（例: `yiw` 単語コピー、`yy` 行コピー） |
| `p` | カーソルの次に貼り付け |
| `P` | カーソルの前に貼り付け |

## Undo / Redo

| キー | 動作 |
|---|---|
| `u` | 元に戻す |
| `Ctrl-r` | やり直す |

## 検索

| キー | 動作 |
|---|---|
| `/` | 前方検索（Enterで確定、`n`で次、`N`で前） |
| `?` | 後方検索 |
| `*` | カーソル下の単語を前方検索 |
| `#` | カーソル下の単語を後方検索 |

## 置換

| コマンド | 動作 |
|---|---|
| `:s/old/new` | 現在行の最初の一致を置換 |
| `:s/old/new/g` | 現在行のすべてを置換 |
| `:%s/old/new/g` | ファイル全体を置換 |

## Visual mode

| キー | 動作 |
|---|---|
| `v` | 文字単位の選択 |
| `V` | 行単位の選択 |
| `Ctrl-v` | 矩形選択 |

選択範囲に対して`d`（削除）、`y`（コピー）、`>`（インデント追加）などが適用できます。

## operator + motion の考え方

Vimの編集操作は **動作(operator) + 範囲(motion)** で構成されます。

```text
d + iw     カーソル位置の単語を削除
c + i(     括弧の中身を変更
y + as     文をコピー
```

- `iw`: inner word（単語の内部）
- `i(`: inner parentheses（括弧の内部）
- `as`: a sentence（文全体）

`i`(inside)は範囲の内部、`a`(around)は区切り文字や空白を含みます。これらはテキストオブジェクトと呼ばれ、[開発効率化ガイド](development-workflow.md)で詳しく説明します。

## ヘルプ

| キー | 動作 |
|---|---|
| `:help` | ヘルプを開く |
| `:help <トピック>` | 特定のトピックを引く |
| `Ctrl-]` | リンク先へ移動（ヘルプ内） |
| `Ctrl-o` | 前の場所へ戻る（ヘルプ内） |
