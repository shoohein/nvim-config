# 開発効率化ガイド

基本操作を習得したあと、少ないキー操作で効率的に編集・移動するためのガイドです。このNeovim設定で追加されたキーマップも含みます。

## buffer, window, tab

この3つを使い分けると、ファイルや表示を自由に管理できます。

| 概念 | 役割 | 操作 |
|---|---|---|
| buffer | 開いているファイル | `:e <file>`, `:bd`, `:ls` |
| window | bufferの表示領域 | 分割、移動、サイズ変更、閉じる |
| tab | windowレイアウトの集合 | `:tabnew`, `:tabclose`, `gt`, `gT` |

tabをブラウザのタブのようにファイル単位で使うのは避けてください。1つのtabに複数のwindowを並べ、必要に応じて別のtabに別のレイアウトを用意するのがVim的です。

## window操作

### 分割

| キー | 動作 |
|---|---|
| `:split` / `:sp` | 水平分割 |
| `:vsplit` / `:vs` | 垂直分割 |
| `Ctrl-w s` | 水平分割 |
| `Ctrl-w v` | 垂直分割 |

### 移動

| キー | 動作 |
|---|---|
| `Ctrl-h` | 左のwindowへ |
| `Ctrl-j` | 下のwindowへ |
| `Ctrl-k` | 上のwindowへ |
| `Ctrl-l` | 右のwindowへ |
| `Ctrl-w w` | 次のwindowへ循環 |

この設定ではNormal modeとTerminal modeの両方で移動できます。Terminal modeから移動するとNormal modeに戻ります。Terminal modeで入力を再開するには`i`を押します。

### サイズ

| キー | 動作 |
|---|---|
| `Ctrl-w =` | すべて同じサイズに |
| `Ctrl-w +` | 高さを増やす |
| `Ctrl-w -` | 高さを減らす |
| `Ctrl-w >` | 幅を増やす |
| `Ctrl-w <` | 幅を減らす |

### 閉じる

| キー | 動作 |
|---|---|
| `Ctrl-w c` | 現在のwindowを閉じる |
| `Ctrl-w o` | 現在のwindow以外をすべて閉じる |
| `:q` | 閉じる（最後のwindowならNeovimを終了） |

## 履歴とジャンプ

| キー | 動作 |
|---|---|
| `Ctrl-o` | ジャンプリストを戻る |
| `Ctrl-i` | ジャンプリストを進む |
| `g;` | 変更リストを戻る |
| `g,` | 変更リストを進む |
| `:jumps` | ジャンプリストの一覧 |
| `:changes` | 変更リストの一覧 |
| `m<a-zA-Z>` | マークを設定 |
| `'<a-zA-Z>` | マークの行頭へ移動 |
| `` `<a-zA-Z> `` | マークの正確な位置へ移動 |

小文字のマーク`a-z`はバッファローカル、大文字のマーク`A-Z`はグローバルです。ジャンプリストは`/`, `G`, `{`, `}` などの大きな移動で記録されます。

`.`（ドット）で直前の変更を繰り返せます。ジャンプと組み合わせると、離れた場所に同じ編集を高速で適用できます。

## テキストオブジェクト

`d`, `c`, `y`, `v` などのoperatorと組み合わせて範囲を指定します。

| 内側 (inner) | 区切り含む (around) | 対象 |
|---|---|---|
| `iw` | `aw` | 単語 |
| `iW` | `aW` | 空白区切りの単語 |
| `is` | `as` | 文 |
| `ip` | `ap` | 段落 |
| `i"` | `a"` | 二重引用符 |
| `i'` | `a'` | 単一引用符 |
| `i(` `i)` | `a(` `a)` | 括弧 |
| `i[` | `a[` | 角括弧 |
| `i{` `i}` | `a{` `a}` | 波括弧 |
| `it` | `at` | XML/HTMLタグ |

```text
ciw     カーソル位置の単語を変更
da"     二重引用符ごと削除
yi(     括弧の中身をコピー
vat     タグの中身を選択
```

## レジスタ

| キー | 動作 |
|---|---|
| `"<a-z>y` | 指定レジスタにコピー |
| `"<a-z>p` | 指定レジスタから貼り付け |
| `"0p` | 最後にyankした内容を貼り付け |
| `"+y` | システムクリップボードにコピー |
| `"+p` | システムクリップボードから貼り付け |
| `:reg` | レジスタの内容を表示 |

削除したテキストはレジスタ`"1`に入ります。最後にyankした内容を貼り付けたいときは`"0p`を使います。

## マクロ

キー操作の記録と再生。

| キー | 動作 |
|---|---|
| `q<a-z>` | 指定レジスタに記録開始 |
| `q` | 記録終了（Normal modeで） |
| `@<a-z>` | 記録したマクロを再生 |
| `<数字>@<a-z>` | 指定回数繰り返し実行 |

組み合わせ例:

```text
qa            記録開始（レジスタa）
A;<Esc>j0     行末にセミコロン追加、次の行先頭へ
q             記録終了
5@a           5回繰り返し
```

## quickfix / location list

`:make`や`:grep`の結果一覧。

| キー | 動作 |
|---|---|
| `:copen` | quickfix windowを開く |
| `:cclose` | quickfix windowを閉じる |
| `:cnext` / `:cprev` | 次/前のアイテムへ |
| `:grep <pattern>` | プロジェクト全体を検索し結果をquickfixへ |

location list（`:lgrep`）はwindowごとに独立した結果一覧です。

## ターミナル

### 起動

| キー | 動作 |
|---|---|
| `<leader>t` | 右側に縦分割でターミナルを開く |
| `:terminal` | 現在のwindowでターミナルを開く |
| `:split \| terminal` | 水平分割 |
| `:vsplit \| terminal` | 垂直分割 |

### Terminal modeの操作

| キー | 動作 |
|---|---|
| `Ctrl-h/j/k/l` | window間を移動（Normal modeになる） |
| `i` | 移動後にターミナル入力を再開 |
| `Ctrl-\ Ctrl-n` | Terminal modeからNormal modeへ |

Terminal modeでは`Ctrl-h`と`Ctrl-l`がwindow移動に割り当てられます。シェル上でこのキーを使う一般的な操作（`Ctrl-h`でバックスペース、`Ctrl-l`で画面クリア）は、Backspaceキーや`clear`コマンドで代用できます。

### 外部コマンド連携

| コマンド | 動作 |
|---|---|
| `:read !<command>` | コマンドの出力をカーソル位置に挿入 |
| `:'<,'>!<command>` | 選択範囲を外部コマンドに渡して置換 |
| `:make` | `makeprg`でビルドし結果をquickfixへ |
| `K` | カーソル下の単語のmanページ（ターミナルモード内） |

## Telescope

この設定で追加されたキーマップです。

| キー | 動作 |
|---|---|
| `<leader>ff` | ファイル検索 |
| `<leader>fg` | テキスト検索（grep） |
| `<leader>fb` | バッファ一覧 |
| `<leader>fh` | ヘルプタグ検索 |

Telescope内では`Ctrl-j`/`Ctrl-k`で上下に選択を移動できます。

## LSP（Language Server Protocol）

この設定で追加されたキーマップです。言語サーバーが起動しているバッファでのみ有効です。

| キー | 動作 |
|---|---|
| `gd` | 定義へ移動 |
| `gD` | 宣言へ移動 |
| `gi` | 実装へ移動 |
| `gr` | 参照一覧（Telescope） |
| `K` | ホバー表示 |
| `Ctrl-k` | シグネチャヘルプ |
| `<leader>rn` | 名前変更 |
| `<leader>ca` | コードアクション |

## 診断（Diagnostics）

| キー | 動作 |
|---|---|
| `<leader>d` | カーソル位置の診断をフロート表示 |
| `[d` | 前の診断へ |
| `]d` | 次の診断へ |
| `<leader>xx` | ワークスペース全体の診断一覧（Trouble） |
| `<leader>xX` | 現在のバッファの診断一覧（Trouble） |

## Neo-tree

| キー | 動作 |
|---|---|
| `<leader>e` | ファイルツリーの表示切り替え |
| `<leader>E` | ファイルツリーで現在のファイルを表示 |

## フォーマット

| キー | 動作 |
|---|---|
| `<leader>f` | バッファ全体をフォーマット |

保存時にも自動でフォーマットされます。

## ワークフロー例

### コードを読む

```text
<leader>e    ファイルツリーを開く
<leader>ff   ファイルを検索して開く
gd           定義へ飛ぶ
Ctrl-o       元の場所へ戻る
gr           すべての参照を見る
K            型やドキュメントを表示
```

### コードを直す

```text
]d           次の診断へ
<leader>d    エラー内容を確認
<leader>ca   修正の候補を表示
<leader>rn   変数名を一括変更
<leader>f    フォーマット
```

### ターミナルと編集を往復

```text
<leader>t    右にターミナルを開く
Ctrl-h       編集側へ戻る
Ctrl-l       ターミナル側へ
i            入力再開
<leader>ff   編集側でファイルを切り替える
```

## 発展: 専用プラグイン

現時点ではNeovim標準機能で運用しています。以下のプラグインは、不便を感じたときに検討してください。

- [toggleterm.nvim](https://github.com/akinsho/toggleterm.nvim): ターミナルの開閉と状態保持
- [overseer.nvim](https://github.com/stevearc/overseer.nvim): ビルド・テストのタスク管理
