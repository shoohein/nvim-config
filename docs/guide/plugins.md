# プラグイン操作ガイド

このNeovim設定で追加されたプラグインのキーマップと操作手順です。

## Telescope

ファイル・テキストのファジー検索です。

| キー         | 動作                                                    |
| ------------ | ------------------------------------------------------- |
| `<leader>ff` | ファイル検索（隠しファイルを含む、gitignore尊重）       |
| `<leader>fg` | テキスト検索（grep、隠しファイルを含む、gitignore尊重） |
| `<leader>fb` | バッファ一覧                                            |
| `<leader>fh` | ヘルプタグ検索                                          |
| `<leader>gg` | 変更ファイル一覧（git_status）                          |

Telescope内では`Ctrl-j`/`Ctrl-k`で上下に選択を移動できます。

### `ge` と `gg` の使い分け

- `<leader>ge`: サイドバーに居座る変更ファイルツリー。眺める・操作する用。
- `<leader>gg`: 一瞬開くファジー検索付きフラットリスト。名前で絞って即ジャンプ用。

## Neo-tree

| キー         | 動作                                 |
| ------------ | ------------------------------------ |
| `<leader>e`  | ファイルツリーの表示切り替え         |
| `<leader>E`  | ファイルツリーで現在のファイルを表示 |
| `<leader>ge` | 変更ファイルのみのツリーに切り替え   |

ツリーは現在のファイルに追従します。変更ファイルにはGit記号（M/A/D/R/C/U）が付きます。ツリー内では`a`作成、`d`削除、`r`リネーム、`c`コピー、`m`移動、`?`ヘルプが使えます。

## oil.nvim

| キー | 動作                               |
| ---- | ---------------------------------- |
| `-`  | 親ディレクトリのファイル一覧を開く |

oil.nvimはファイル一覧をバッファとして開き、そのまま編集してリネーム・作成・移動・削除を行う編集型ファイラです。ツリー表示のneo-treeとは用途が異なり、ファイル名の一括変更やディレクトリ構造の編集に適しています。`<CR>`でファイルを開き、`<C-s>`で縦分割、`<C-v>`で横分割して開けます。

## ターミナルパネル

[toggleterm.nvim](https://github.com/akinsho/toggleterm.nvim)による下パネルです。閉じてもプロセスは保持されます。

| キー/コマンド                    | 動作                                |
| -------------------------------- | ----------------------------------- |
| `<C-`>`/`<leader>t\`             | 下パネルの開閉トグル                |
| `Esc` / `jj`                     | Terminal modeからNormal modeへ      |
| `i`                              | Normal modeからターミナル入力へ復帰 |
| `Ctrl-h/j/k/l`                   | window間を移動                      |
| `:ToggleTerm direction=vertical` | 縦分割で開く例                      |
| `:ToggleTerm direction=float`    | フロートで開く例                    |
| `:ToggleTerm 2`                  | 2番目のターミナルを開く例           |

Terminal modeでは`Ctrl-h`と`Ctrl-l`がwindow移動に割り当てられます。シェル上でこのキーを使う一般的な操作（`Ctrl-h`でバックスペース、`Ctrl-l`で画面クリア）は、Backspaceキーや`clear`コマンドで代用できます。

```text
<leader>t    下にターミナルを開く
Ctrl-h       編集側へ戻る
Ctrl-l       ターミナル側へ
i            入力再開
<leader>ff   編集側でファイルを切り替える
```

## 補完

blink.cmpは`super-tab`プリセットを使用します。Insert modeでは、`<Tab>`で補完候補を確定し、`<S-Tab>`で前のスニペットプレースホルダーへ移動します。`<Up>` / `<Down>`または`<C-p>` / `<C-n>`で候補を移動し、`<C-Space>`で補完メニューを表示、`<C-e>`で補完をキャンセルできます。処理できない場合は通常のキー操作へフォールバックします。

候補はLSP、パス、スニペット、現在のバッファから取得します。補完ドキュメントは自動表示しません。

## LSP（Language Server Protocol）

言語サーバーが起動しているバッファでのみ有効です。

| キー         | 動作                  |
| ------------ | --------------------- |
| `gd`         | 定義へ移動            |
| `gD`         | 宣言へ移動            |
| `gi`         | 実装へ移動            |
| `gr`         | 参照一覧（Telescope） |
| `K`          | ホバー表示            |
| `Ctrl-k`     | シグネチャヘルプ      |
| `<leader>rn` | 名前変更              |
| `<leader>ca` | コードアクション      |

## 診断（Diagnostics）

| キー         | 動作                                    |
| ------------ | --------------------------------------- |
| `<leader>d`  | カーソル位置の診断をフロート表示        |
| `[d`         | 前の診断へ                              |
| `]d`         | 次の診断へ                              |
| `<leader>xx` | ワークスペース全体の診断一覧（Trouble） |
| `<leader>xX` | 現在のバッファの診断一覧（Trouble）     |

## フォーマット

| キー        | 動作                                                               |
| ----------- | ------------------------------------------------------------------ |
| `<leader>f` | Normal modeではバッファ全体、Visual modeでは選択範囲をフォーマット |

フォーマッタが設定されている言語では、保存時に自動でフォーマットされます（対応言語は `:ConformInfo` で確認できます）。バッファを開いた時点で設定が読み込まれるため、最初の保存から自動でフォーマットされます。

## Git差分

### ナビゲーション

| キー | 動作          |
| ---- | ------------- |
| `]c` | 次のGit変更へ |
| `[c` | 前のGit変更へ |

vimdiff中はNeovim標準の差分移動（`]c` / `[c`）として動作します。

### 変更操作

| キー            | 動作                                                    |
| --------------- | ------------------------------------------------------- |
| `<leader>gs`    | カーソル行の変更をステージ                              |
| `<leader>gr`    | カーソル行の変更を元に戻す                              |
| `<leader>gq`    | バッファ内の変更一覧を表示（quickfix）                  |
| `<leader>gb`    | 行のBlameを表示                                         |
| `<leader>gp`    | カーソル行の差分をプレビュー                            |
| `<leader>gi`    | カーソル行の差分をインライン表示                        |
| `ih` (Operator) | Git変更ブロックを選択（`vih` で選択、`cih` で変更など） |

変更の表示はデフォルトでindex（ステージングエリア）を基準とし、未ステージの変更とステージ済みの変更を区別して表示します。
