# プラグイン操作ガイド

このNeovim設定で追加されたプラグインのキーマップと操作手順です。

## Telescope

ファイル・テキストのファジー検索です。

| キー         | 動作                                                    | 覚え方               |
| ------------ | ------------------------------------------------------- | -------------------- |
| `<leader>ff` | ファイル検索（隠しファイルを含む、gitignore尊重）       | **f**ind **f**iles   |
| `<leader>fg` | テキスト検索（grep、隠しファイルを含む、gitignore尊重） | **f**ind **g**rep    |
| `<leader>fb` | バッファ一覧                                            | **f**ind **b**uffers |
| `<leader>fh` | ヘルプタグ検索                                          | **f**ind **h**elp    |
| `<leader>gg` | 変更ファイル一覧（git_status）                          | **g**it 状態一覧     |

Telescope内では`Ctrl-j`/`Ctrl-k`で上下に選択を移動できます。

### `ge` と `gg` の使い分け

- `<leader>ge`: サイドバーに表示する変更ファイルツリー。ツリーでの確認・操作用。
- `<leader>gg`: ファジー検索付きの変更ファイル一覧。名前で絞って移動用。

## Neo-tree

| キー         | 動作                                 | 覚え方                 |
| ------------ | ------------------------------------ | ---------------------- |
| `<leader>e`  | ファイルツリーの表示切り替え         | **e**xplorer           |
| `<leader>E`  | ファイルツリーで現在のファイルを表示 |                        |
| `<leader>ge` | 変更ファイルのみのツリーに切り替え   | **g**it + **e**xplorer |

ツリーは現在のファイルに追従します。変更ファイルにはGit記号（M/A/D/R/C/U）が付きます。

| キー | 動作             | 覚え方     |
| ---- | ---------------- | ---------- |
| `a`  | ファイルの作成   | **a**dd    |
| `d`  | ファイルの削除   | **d**elete |
| `r`  | ファイル名の変更 | **r**ename |
| `c`  | コピー           | **c**opy   |
| `m`  | 移動             | **m**ove   |
| `?`  | ヘルプの表示     |            |

## oil.nvim

| キー | 動作                               |
| ---- | ---------------------------------- |
| `-`  | 親ディレクトリのファイル一覧を開く |

oil.nvimはファイル一覧をバッファとして開き、そのまま編集してリネーム・作成・移動・削除を行う編集型ファイラです。ファイル名の一括変更やディレクトリ構造の編集に適しています。

## バッファ一覧

画面上部に開いているbufferを番号・ファイル種別アイコン・ファイル名付きで表示します。表示される番号はbuffer番号なので、`:b <番号>`で直接移動できます。

## ターミナルパネル

[toggleterm.nvim](https://github.com/akinsho/toggleterm.nvim)による下パネルです。閉じてもプロセスは保持されます。

| キー/コマンド                    | 動作                                | 覚え方              |
| -------------------------------- | ----------------------------------- | ------------------- |
| `<leader>t`                      | 下パネルの開閉トグル                | **t**erminal        |
| `Esc` / `jj`                     | Terminal modeからNormal modeへ      |                     |
| `i`                              | Normal modeからターミナル入力へ復帰 |                     |
| `Ctrl-h/j/k/l`                   | window間を移動                      | Vim移動キーそのまま |
| `:ToggleTerm direction=vertical` | 縦分割で開く例                      |                     |
| `:ToggleTerm direction=float`    | フロートで開く例                    |                     |
| `:ToggleTerm 2`                  | 2番目のターミナルを開く例           |                     |

Terminal modeでは`Ctrl-h`と`Ctrl-l`がwindow移動に割り当てられます。シェル上でこのキーを使う一般的な操作（`Ctrl-h`でバックスペース、`Ctrl-l`で画面クリア）は、Backspaceキーや`clear`コマンドで代用できます。

## 補完

blink.cmpは`super-tab`プリセットを使用します。

| キー                                 | 動作                                 | 覚え方                  |
| ------------------------------------ | ------------------------------------ | ----------------------- |
| `<Tab>`                              | 候補の確定                           |                         |
| `<S-Tab>`                            | 前のスニペットプレースホルダーへ移動 |                         |
| `<Up>` / `<Down>`、`<C-p>` / `<C-n>` | 候補の移動                           | **p**revious / **n**ext |
| `<C-Space>`                          | 補完メニューの表示                   |                         |
| `<C-e>`                              | 補完のキャンセル                     |                         |

候補はLSP、パス、スニペット、現在のバッファから取得します。

## LSP（Language Server Protocol）

言語サーバーが起動しているバッファでのみ有効です。
`gi`/`gr`/`gy` は一覧から選ぶ形式（Telescope）で、`gd`/`gD` は直接移動します。

| キー         | 動作                              | 覚え方                    |
| ------------ | --------------------------------- | ------------------------- |
| `gd`         | 定義へ移動                        | **g**o **d**efinition     |
| `gD`         | 宣言へ移動                        | **g**o **D**eclaration    |
| `gi`         | 実装へ移動（一覧・Telescope）     | **g**o **i**mplementation |
| `gr`         | 参照一覧（Telescope）             | **g**o **r**eferences     |
| `gy`         | 型定義へ移動（一覧・Telescope）   | **g**o t**y**pe           |
| `K`          | ホバー表示                        | **k**eyword               |
| `Ctrl-s`     | シグネチャヘルプ（Normal/Insert） | **s**ignature             |
| `<leader>rn` | 名前変更                          | **r**e**n**ame            |
| `<leader>ca` | コードアクション（Normal/Visual） | **c**ode **a**ction       |
| `<leader>ds` | 文書シンボル一覧（Telescope）     | **d**ocument **s**ymbols  |
| `<leader>ws` | ワークスペースシンボル検索        | **w**orkspace **s**ymbols |
| `<leader>th` | インレイヒント表示の切り替え      | **t**oggle **h**int       |

## 診断（Diagnostics）

行末に短文、行番号の左に種別アイコンを表示します。入力中は更新しません。
カーソルを止めると数百ms後に理由を自動表示します（フォーカスは奪いません）。

| キー         | 動作                                    | 覚え方                 |
| ------------ | --------------------------------------- | ---------------------- |
| `<leader>d`  | カーソル位置の診断をフロート表示        | **d**iagnostics        |
| `[d`         | 前の診断へ                              | 前へ + **d**iagnostics |
| `]d`         | 次の診断へ                              | 次へ + **d**iagnostics |
| `<leader>xx` | ワークスペース全体の診断一覧（Trouble） | **x**=cross全体        |
| `<leader>xX` | 現在のバッファの診断一覧（Trouble）     | **x**=cross今の文書    |

エラーが出たらこの順で確認します。

1. 赤波線と行末の短文を確認する
1. カーソルを止めて理由表示を見る（出なければ `<leader>d`）
1. `[d` / `]d` で前後の診断へ移動する
1. `<leader>xx` / `<leader>xX` の一覧が空になれば正常に戻ったと判断する

## フォーマット

| キー        | 動作                                                               | 覚え方     |
| ----------- | ------------------------------------------------------------------ | ---------- |
| `<leader>f` | Normal modeではバッファ全体、Visual modeでは選択範囲をフォーマット | **f**ormat |

フォーマッタが設定されている言語では、保存時に自動でフォーマットされます。対応言語は `:ConformInfo` で確認できます。

## Git差分

### ナビゲーション

| キー | 動作          | 覚え方            |
| ---- | ------------- | ----------------- |
| `]c` | 次のGit変更へ | 次へ + **c**hange |
| `[c` | 前のGit変更へ | 前へ + **c**hange |

vimdiff中はNeovim標準の差分移動として動作します。

### 変更操作

| キー            | 動作                                                    | 覚え方                     |
| --------------- | ------------------------------------------------------- | -------------------------- |
| `<leader>gs`    | カーソル行の変更をステージ                              | **g**it **s**tage          |
| `<leader>gr`    | カーソル行の変更を元に戻す                              | **g**it **r**eset          |
| `<leader>gq`    | バッファ内の変更一覧を表示（quickfix）                  | **g**it **q**uickfixへ送る |
| `<leader>gb`    | 行のBlameを表示                                         | **g**it **b**lame          |
| `<leader>gp`    | カーソル行の差分をプレビュー                            | **g**it **p**review        |
| `<leader>gi`    | カーソル行の差分をインライン表示                        | **g**it **i**nline         |
| `ih` (Operator) | Git変更ブロックを選択（`vih` で選択、`cih` で変更など） | **i**nner **h**unk         |
