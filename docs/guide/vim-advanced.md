# 開発効率化ガイド

基本操作を習得したあと、少ないキー操作で効率的に編集・移動するためのガイドです。

## buffer, window, tab

この3つを使い分けると、ファイルや表示を自由に管理できます。

| 概念   | 役割                   | 操作                               |
| ------ | ---------------------- | ---------------------------------- |
| buffer | 開いているファイル     | `:e <file>`, `:bd`, `:ls`          |
| window | bufferの表示領域       | 分割、移動、サイズ変更、閉じる     |
| tab    | windowレイアウトの集合 | `:tabnew`, `:tabclose`, `gt`, `gT` |

tabをブラウザのタブのようにファイル単位で使うのは避けてください。1つのtabに複数のwindowを並べ、必要に応じて別のtabに別のレイアウトを用意するのがVim的です。

| 操作        | 動作                   |
| ----------- | ---------------------- |
| `:b <番号>` | 指定したbufferへ移動   |
| `:bn`       | 次のbufferへ移動       |
| `:bp`       | 前のbufferへ移動       |
| `:ls`       | buffer一覧と番号を表示 |

buffer番号は詰め直されないため、左から何番目かとは一致しない場合があります。この設定のbuffer表示は[プラグイン操作ガイド](plugins.md#%E3%83%90%E3%83%83%E3%83%95%E3%82%A1%E4%B8%80%E8%A6%A7)を参照してください。

## window操作

### 分割

| キー              | 動作     |
| ----------------- | -------- |
| `:split` / `:sp`  | 水平分割 |
| `:vsplit` / `:vs` | 垂直分割 |
| `Ctrl-w s`        | 水平分割 |
| `Ctrl-w v`        | 垂直分割 |

### 移動

| キー       | 動作             |
| ---------- | ---------------- |
| `Ctrl-w h` | 左のwindowへ     |
| `Ctrl-w j` | 下のwindowへ     |
| `Ctrl-w k` | 上のwindowへ     |
| `Ctrl-w l` | 右のwindowへ     |
| `Ctrl-w w` | 次のwindowへ循環 |

この設定では`Ctrl-h/j/k/l`にもwindow移動を割り当てています（Terminal mode含む）。

### サイズ

| キー       | 動作               |
| ---------- | ------------------ |
| `Ctrl-w =` | すべて同じサイズに |
| `Ctrl-w +` | 高さを増やす       |
| `Ctrl-w -` | 高さを減らす       |
| `Ctrl-w >` | 幅を増やす         |
| `Ctrl-w <` | 幅を減らす         |

### 閉じる

| キー       | 動作                                   |
| ---------- | -------------------------------------- |
| `Ctrl-w c` | 現在のwindowを閉じる                   |
| `Ctrl-w o` | 現在のwindow以外をすべて閉じる         |
| `:q`       | 閉じる（最後のwindowならNeovimを終了） |

## 履歴とジャンプ

| キー            | 動作                     |
| --------------- | ------------------------ |
| `Ctrl-o`        | ジャンプリストを戻る     |
| `Ctrl-i`        | ジャンプリストを進む     |
| `g;`            | 変更リストを戻る         |
| `g,`            | 変更リストを進む         |
| `:jumps`        | ジャンプリストの一覧     |
| `:changes`      | 変更リストの一覧         |
| `m<a-zA-Z>`     | マークを設定             |
| `'<a-zA-Z>`     | マークの行頭へ移動       |
| `` `<a-zA-Z> `` | マークの正確な位置へ移動 |

小文字のマーク`a-z`はバッファローカル、大文字のマーク`A-Z`はグローバルです。ジャンプリストは`/`, `G`, `{`, `}` などの大きな移動で記録されます。

`.`（ドット）で直前の変更を繰り返せます。ジャンプと組み合わせると、離れた場所に同じ編集を高速で適用できます。

## テキストオブジェクト

`d`, `c`, `y`, `v` などのoperatorと組み合わせて範囲を指定します。

| 内側 (inner) | 区切り含む (around) | 対象             |
| ------------ | ------------------- | ---------------- |
| `iw`         | `aw`                | 単語             |
| `iW`         | `aW`                | 空白区切りの単語 |
| `is`         | `as`                | 文               |
| `ip`         | `ap`                | 段落             |
| `i"`         | `a"`                | 二重引用符       |
| `i'`         | `a'`                | 単一引用符       |
| `i(` `i)`    | `a(` `a)`           | 括弧             |
| `i[`         | `a[`                | 角括弧           |
| `i{` `i}`    | `a{` `a}`           | 波括弧           |
| `it`         | `at`                | XML/HTMLタグ     |

```text
ciw     カーソル位置の単語を変更
da"     二重引用符ごと削除
yi(     括弧の中身をコピー
vat     タグの中身を選択
```

## レジスタ

| キー      | 動作                               |
| --------- | ---------------------------------- |
| `"<a-z>y` | 指定レジスタにコピー               |
| `"<a-z>p` | 指定レジスタから貼り付け           |
| `"0p`     | 最後にyankした内容を貼り付け       |
| `"+y`     | システムクリップボードにコピー     |
| `"+p`     | システムクリップボードから貼り付け |
| `:reg`    | レジスタの内容を表示               |

削除したテキストはレジスタ`"1`に入ります。最後にyankした内容を貼り付けたいときは`"0p`を使います。

## マクロ

キー操作の記録と再生。

| キー           | 動作                      |
| -------------- | ------------------------- |
| `q<a-z>`       | 指定レジスタに記録開始    |
| `q`            | 記録終了（Normal modeで） |
| `@<a-z>`       | 記録したマクロを再生      |
| `<数字>@<a-z>` | 指定回数繰り返し実行      |

組み合わせ例:

```text
qa            記録開始（レジスタa）
A;<Esc>j0     行末にセミコロン追加、次の行先頭へ
q             記録終了
5@a           5回繰り返し
```

## quickfix / location list

`:make`や`:grep`の結果一覧。

| キー                | 動作                                |
| ------------------- | ----------------------------------- |
| `:copen`            | quickfix windowを開く               |
| `:cclose`           | quickfix windowを閉じる             |
| `:cnext` / `:cprev` | 次/前のアイテムへ                   |
| `:grep <args>`      | `grepprg`で検索し、結果をquickfixへ |

location list（`:lgrep`）はwindowごとに独立した結果一覧です。

## ターミナル

トグル式の下パネルを使う場合は[プラグイン操作ガイド](plugins.md#%E3%82%BF%E3%83%BC%E3%83%9F%E3%83%8A%E3%83%AB%E3%83%91%E3%83%8D%E3%83%AB)を参照してください。ここではVim標準の操作を説明します。

### 起動

| キー                  | 動作                           |
| --------------------- | ------------------------------ |
| `:terminal`           | 現在のwindowでターミナルを開く |
| `:split \| terminal`  | 水平分割                       |
| `:vsplit \| terminal` | 垂直分割                       |

### Terminal modeの操作

| キー            | 動作                           |
| --------------- | ------------------------------ |
| `Ctrl-\ Ctrl-n` | Terminal modeからNormal modeへ |

この設定のwindow移動キー（`Ctrl-h/j/k/l`）とその注意点は[プラグイン操作ガイド](plugins.md#%E3%82%BF%E3%83%BC%E3%83%9F%E3%83%8A%E3%83%AB%E3%83%91%E3%83%8D%E3%83%AB)を参照してください。

### 外部コマンド連携

| コマンド           | 動作                                |
| ------------------ | ----------------------------------- |
| `:read !<command>` | コマンドの出力をカーソル位置に挿入  |
| `:'<,'>!<command>` | 選択範囲を外部コマンドに渡して置換  |
| `:make`            | `makeprg`でビルドし結果をquickfixへ |
