# guideの書き方

共通規則は[文書規約](docs-conventions.md)に従う。

- `vim-basics.md` / `vim-advanced.md` にプラグイン固有の内容を混在させない。プラグイン固有は `plugins.md` に置く。

| ファイル          | 置く内容                                                      | 置かない内容         |
| ----------------- | ------------------------------------------------------------- | -------------------- |
| `vim-basics.md`   | モード、移動、編集、検索、置換など基本操作                    | プラグイン固有の操作 |
| `vim-advanced.md` | window管理、履歴、テキストオブジェクトなどVim標準の効率化操作 | プラグイン固有の操作 |
| `plugins.md`      | プラグイン固有のキーマップと操作手順                          | Vim標準の操作        |
